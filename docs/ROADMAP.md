# MoonRewardForge Roadmap

Planned follow-ups if the project continues beyond the competition:

1. Load reward traces from structured files instead of only built-in scenarios.
2. Add per-term normalization strategies and comparison reports.
3. Export summaries as JSON for downstream dashboards.
4. Add simple visualizations for sparse reward and clipping patterns.
5. Add environment presets for robotics, games, and offline RL workflows.

The current scope stays intentionally compact so the project remains easy to review.
